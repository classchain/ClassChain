## About the Project

**ClassChain** is a transparent, anti-corruption, and decentralized funding protocol for building schools in underserved areas of Iran.

By combining **blockchain**, **NFT**, and **DAO** technologies, it enables direct participation of donors from inside and outside Iran, as well as international volunteers — without intermediaries, without a native token, and with full transparency.

> Building a school is not just constructing a building; it is building a bright and sustainable future.

---

## Key Features

| Feature | Description |
|---------|-------------|
| **Direct USDT Acceptance** | No native token. All contributions are made by direct USDT transfers. |
| **Multi-Chain Support** | Compatible with both EVM and TVM networks for broader access and higher resilience. |
| **Participation NFTs** | Every valid contribution results in an NFT as a certificate of participation and voting right. |
| **DAO Governance** | The community decides on project priorities, resource allocation, and school naming. |
| **Transparent WebGIS** | Live map of projects, physical & financial progress, and on-chain transaction tracking in a single dashboard. |
| **Sanctions-Resistant** | Independent of the domestic banking system; continues to function even during economic crises. |

## Why ClassChain?

Traditional school-building models face serious challenges:

- Centralized decision-making and lack of transparency
- No mechanism for small and continuous contributions
- Difficulty for Iranians living abroad to participate
- Vulnerability to sanctions and banking crises
- Lack of incentives aligned with the digital generation

**ClassChain** bridges these gaps with a transparent, democratic, and technology-driven model.

## How It Works

```
1. Donors send USDT directly to a project wallet or the general pool
          ↓
2. Smart contract issues a participation NFT (certificate + voting right)
          ↓
3. The community uses the DAO to set project priorities and allocate funds
          ↓
4. Project progress is visible in real time on WebGIS and on-chain
```

### Two Contribution Models

- **Project-Specific Wallet**  
  Major donors can fully or largely fund a specific school project.

- **General Contribution Pool**  
  Small donations are collected in a shared pool. NFT holders (via DAO) vote on which project receives the funds.

## Technical Architecture (Summary)

- **Blockchain**: Multi-chain (EVM + TVM)
- **Funding**: USDT and supported stablecoins
- **Participation Certificate**: NFT (ERC-721 / ERC-1155 and TVM equivalents)
- **Governance**: NFT-based DAO
- **Transparency Layer**: WebGIS + live dashboard + chain explorers
- **Contracts**: Open-source (actively developed on the `Mobile` branch)

## Governance Structure

- Each **NFT** equals **one vote**.
- Major donors vote within their project-specific DAO.
- Small donors participate in the general DAO for pool project selection.
- Key decisions (location priority, school naming, fund allocation) are made by the community.
