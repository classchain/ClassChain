# پنل اصلی ادمین (`Admin/index.html`)

پنل مدیریت پروژه‌ها و ساخت خزانه‌های روی زنجیره.

**عنوان صفحه:** پنل مدیریت - ClassChain  
**زبان و جهت:** فارسی / RTL

---

## ساختار کلی صفحه

- **هدر:** لوگو + وضعیت ورود ادمین + وضعیت اتصال شبکه
- **سایدبار راست:** منوی ناوبری
- **محتوای اصلی:** بخش‌های مختلف بر اساس انتخاب منو

### منوی سایدبار

| آیتم | بخش | توضیح کوتاه |
|------|------|-------------|
| افزودن پروژه | `section-add-project` | ثبت پروژه جدید در Projects.json |
| ساخت خزانه | `section-create` | استقرار قرارداد خزانه روی شبکه |
| پروژه‌ها | `section-projects` | جدول لیست پروژه‌ها |
| تنظیمات | `section-settings` | تنظیمات دسترسی ذخیره‌سازی |

## ۱. افزودن پروژه جدید

### هدف
افزودن یک پروژه مدرسه جدید به فایل `frontend/data/Projects.json` تا بعداً بتوان برای آن خزانه ساخت.

### فیلدهای فرم

#### الزامی
- **آیدی پروژه (ProjectID)** — مثال: `2501`
- **نام پروژه**
- **هدف مالی (USDT)**

#### اختیاری / تکمیلی
- استان
- منطقه
- آدرس پروژه
- تعداد کلاس
- زیربنا (متر)
- طول جغرافیایی (x)
- عرض جغرافیایی (y)
- محل اجرا (شهری / روستایی)
- ماهیت پروژه (پیش‌فرض: خیرین)
- نوع پروژه / نیاز (پیش‌فرض: احداث فضای آموزشی جهت ارتقاء سرانه فضا)
- مسئول پروژه
- شماره تلفن مسئول
- کد فضا

### رفتار پس از ذخیره
1. پروژه به لیست داخلی اضافه می‌شود.
2. خروجی JSON به‌روزشده نمایش داده می‌شود.
3. دو دکمه ظاهر می‌شود:
   - **آپلود به GitHub** — ذخیره نهایی از طریق GitHub Proxy Worker
   - **ساخت خزانه برای این پروژه** — انتقال مستقیم به بخش ساخت خزانه با ProjectID پرشده

### نکات
- تا زمانی که «آپلود به GitHub» زده نشود، پروژه روی مخزن اصلی ثبت نمی‌شود.
- بعد از آپلود، چند ثانیه صبر کنید و سپس در بخش ساخت خزانه دکمه «بررسی» را بزنید.

---

## ۲. ساخت خزانه

### هدف
استقرار قرارداد خزانه (SchoolTokenFund یا معادل Multisig) روی شبکه انتخاب‌شده و ثبت آدرس آن در Projects.json.

### مراحل

1. **انتخاب شبکه**  
   تب‌های شبکه از لیست `ACTIVE_NETWORKS` رندر می‌شوند (شامل نشان تست‌نت/مایننت).

2. **وارد کردن ProjectID و بررسی**  
   دکمه «بررسی» پروژه را از Projects.json می‌خواند و اطلاعات فعلی آن (شامل خزانه‌های موجود) را نمایش می‌دهد.

3. **انتخاب نوع مالکیت**
   - **تک‌مالکی:** یک آدرس مالک
   - **چندمالکی (Multisig):** لیست آدرس مالکان + تعداد امضای لازم

4. **ساخت**  
   دکمه «ساخت خزانه» تراکنش را ارسال می‌کند.

### جزئیات فنی پس از ساخت
- آدرس خزانه از رویداد `FundCreated` یا روش‌های جایگزین (logs، receipt، getFundAddress) استخراج می‌شود.
- برای شبکه‌های TVM آدرس‌ها به فرمت Base58 نرمال می‌شوند.
- مقدار `scanFromBlock` (بلاک تراکنش ساخت) ثبت می‌شود تا Indexer از همان نقطه اسکن را شروع کند.
- اطلاعات زیر در Projects.json به‌روز می‌شود:
  - `address`
  - `multisigAddress` (در صورت وجود)
  - `owners`
  - `requiredSignatures`
  - `scanFromBlock`

### خطاهای رایج
- پروژه یافت نشد → ابتدا پروژه را اضافه و آپلود کنید.
- آدرس مالک نامعتبر
- تعداد امضا بیشتر از تعداد مالکان
- عدم اتصال کیف‌پول

---

## ۳. لیست پروژه‌ها

- جدول تمام پروژه‌ها
- فیلتر بر اساس شبکه
- دکمه Refresh
- نمایش وضعیت خزانه‌های هر پروژه در شبکه‌های مختلف

---

## ۴. تنظیمات

- بخش مربوط به دسترسی ذخیره‌سازی
- توضیح: ذخیره تغییرات از طریق سرویس امن انجام می‌شود؛ توکن GitHub را در این صفحه وارد یا ذخیره نکنید.

## جریان کاری پیشنهادی

```
افزودن پروژه → آپلود به GitHub → ساخت خزانه (یک یا چند شبکه) → بررسی در لیست پروژه‌ها
```
