# پنل‌های مدیریت ClassChain

فولدر `Admin/` شامل دو پنل عملیاتی جدا از هم است که برای مدیریت پروژه‌ها، ساخت خزانه، نظارت مالی و عملیات تخصیص استفاده می‌شوند.

| صفحه | فایل | نقش اصلی |
|------|------|----------|
| پنل اصلی ادمین | [`index.html`](../../Admin/index.html) | افزودن پروژه، ساخت خزانه، مشاهده لیست پروژه‌ها |
| مرکز راهبری (Ops) | [`ops.html`](../../Admin/ops.html) | نظارت مالی، سلامت Indexer، جامعه/FIFO، رأی‌گیری، تخصیص خزانه |

## پیش‌نیازهای مشترک

- ورود ادمین با **GitHub OAuth** (از طریق Worker پروکسی)
- اتصال کیف‌پول (MetaMask برای EVM / TronLink برای TVM)
- سرو کردن سایت از ریشه ریپو (نه `file://`)
- دسترسی به `Projects.json` و در صورت نیاز Indexer Secret

## جریان کاری پیشنهادی کلی

1. ورود با GitHub در پنل اصلی
2. افزودن پروژه جدید
3. ساخت خزانه برای پروژه در شبکه(های) مورد نظر
4. نظارت و عملیات مالی از مرکز راهبری (Ops)

## نکات مهم

- پنل Ops از پنل اصلی جدا شده است تا مسئولیت‌های «مدیریت پروژه» و «عملیات مالی/اجرایی» از هم تفکیک شوند.
- تمام عملیات ذخیره‌سازی تغییرات روی `Projects.json` از طریق سرویس امن (GitHub Proxy Worker) انجام می‌شود.
- توکن GitHub و Indexer Secret هرگز در localStorage یا کد فرانت ذخیره نمی‌شوند.
