# مرکز راهبری ClassChain (`Admin/ops.html`)

پنل عملیاتی برای نظارت مالی، سلامت Indexer، مدیریت جامعه، رأی‌گیری و تخصیص وجوه.

**عنوان صفحه:** مرکز راهبری ClassChain  
**زیرعنوان:** مالی · Indexer · FIFO · رأی · تخصیص — مقیاس‌پذیر برای n شبکه

---

## نوار ابزار بالای صفحه

| عنصر | عملکرد |
|------|--------|
| فیلتر شبکه | محدود کردن داده‌ها به یک شبکه خاص |
| فیلد Indexer Secret | وارد کردن رمز دسترسی به APIهای Indexer |
| دکمه Secret | ذخیره موقت Secret در session |
| دکمه بروزرسانی | بارگذاری مجدد تمام داده‌ها |
| چک‌باکس auto 60s | رفرش خودکار هر ۶۰ ثانیه |
| لینک «پنل اصلی» | بازگشت به `index.html` |

---

## تب ۱: نمای کلی (Overview)

### KPIها
- **TVL پروژه‌ها:** جمع موجودی خزانه‌های پروژه‌ها (بدون GENERAL_POOL)
- **GENERAL_POOL:** موجودی خزانه عمومی
- **پیشرفت کل:** نسبت raised به target پروژه‌ها
- **تعداد پروژه:** بدون احتساب GENERAL_POOL
- **وضعیت Indexer**

### عناصر بصری
- نمودار دونات پیشرفت مالی کل
- نمودار میله‌ای موجودی پروژه‌ها به تفکیک شبکه
- کارت اختصاصی GENERAL_POOL با موجودی per-network

### لیست پروژه‌ها
- کارت‌های پروژه با نوار پیشرفت
- امکان مرتب‌سازی بر اساس:
  - درصد پیشرفت
  - موجودی
  - هدف مالی
  - شناسه پروژه
- کلیک روی هر کارت → باز شدن **Drawer** جزئیات شامل:
  - پیشرفت و مبالغ
  - موجودی per-network
  - آدرس خزانه‌ها
  - دکمه Sync Indexer برای همان پروژه

## تب ۲: سلامت Indexer

### جدول وضعیت اسکن
ستون‌ها:
- پروژه
- شبکه
- آخرین بلاک
- Lag
- تعداد Tx
- وضعیت
- خطا

### عملیات
- **Sync پروژه:** وارد کردن ProjectID و همگام‌سازی فقط همان پروژه
- **Sync همه:** همگام‌سازی تمام پروژه‌ها (با تأیید کاربر)
- نمایش لاگ عملیات در پایین صفحه

---

## تب ۳: جامعه / FIFO

- فیلتر شبکه
- لیست **Contributors**
- نمایش **صف FIFO** (ترتیب قطعی واریز donors)
- صف FIFO مبنای تخصیص وجوه در تب تخصیص است

---

## تب ۴: رای‌گیری

### لیست راندها
- نمایش راندهای موجود + دکمه جزئیات
- بروزرسانی لیست

### باز کردن راند جدید
- عنوان راند (الزامی)
- لیست پروژه‌های کاندید (با کاما یا فاصله)
- **محدودیت:** فقط یک راند باز همزمان مجاز است

### بستن راند
- ابتدا از لیست، «جزئیات» راند باز را باز کنید تا شناسه پر شود
- وارد کردن **پروژه منتخب** الزامی است
- بستن بدون پروژه منتخب مجاز نیست
- تخصیص مالی واقعی در تب «تخصیص خزانه» انجام می‌شود

---

## تب ۵: تخصیص خزانه (Disburse)

### بخش اول: وضعیت تخصیص راندها
- لیست راندها و وضعیت تخصیص آن‌ها
- امکان وارد کردن مبلغ دستی (USDT)
- اگر مبلغ خالی باشد، از target پروژه استفاده می‌شود
- تخصیص بر اساس **صف FIFO قطعی** انجام می‌شود (نه تصادفی)
- سیستم از موجودی آزاد صف بیشتر برنمی‌دارد
- تخصیص فقط روی شبکه‌هایی انجام می‌شود که پروژه در آن‌ها خزانه دارد

### بخش دوم: درخواست‌های انتقال on-chain
- هر شبکه یک کارت جداگانه
- مسیر انتقال: `GENERAL_POOL → خزانه پروژه`
- تشخیص خودکار تک‌امضا یا چندامضا از روی `Projects.json`
- برای هر Owner دکمه اختصاصی
- پس از امضا/اجرای موفق، دکمه قفل می‌شود
- **نکته مهم:** کارمزد (gas/fee) توسط خود شبکه تعیین می‌شود و سایت هیچ محاسبه‌ای انجام نمی‌دهد

---

## نکات عملیاتی مهم

1. همیشه ابتدا وضعیت Indexer را در تب سلامت بررسی کنید.
2. قبل از تخصیص، از صحت صف FIFO مطمئن شوید.
3. راند رأی‌گیری را فقط زمانی ببندید که پروژه منتخب قطعی شده باشد.
4. برای عملیات on-chain، کیف‌پول مربوط به Owner باید متصل باشد.
5. فیلتر شبکه روی تمام محاسبات مالی و نمایش‌ها تأثیر می‌گذارد.
